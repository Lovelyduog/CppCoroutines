# ADR-0001: 学习代码与库代码分离的目录结构

日期：2026-09-10 ｜ 状态：已接受

## 背景

仓库从根目录平铺的学习文件演化为「学习 + 自研协程库」双职能，需要一个不互相拖累的结构。

## 决策

- 库代码占 `include/`（公开头文件）与 `src/`（实现），以 INTERFACE 库 `cppcoroutines` 起步；库名/命名空间待定，定下后只改 `include/` 下层目录。
- 学习代码全部归 `study/`：`lesson/`（基础学习）、`test/`（实验演进）、`common/`（共享头文件）、`external/`（他人实践，不参与根构建）。
- 第三方暂留空 `thirdparty/`；依赖 boost 的学习程序排除出构建，而不是硬编码他人机器路径。

## 后果

- 库可以独立于学习代码成长、发布、重构。
- 他人实践目录保留原样，失去根构建覆盖（原本也因硬编码路径而不可用），需要时单独构建。
- boost 相关文件恢复编译依赖第三方引入决策（见 PROJECT-STRUCTURE.md 后续待定）。
